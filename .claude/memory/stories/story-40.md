## 📋 Задача (analyst)

**Ограничения:** Реализации для `single`; Бизнес-задачи worker-а (эскалации, очистка, импорт файлов); Продвинутая обработка отказов Redis, ретраи, метрики; Docker-образы и compose (отдельная story)
